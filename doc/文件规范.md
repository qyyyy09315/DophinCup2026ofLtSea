## 文件命名规则

### Python 脚本
| 前缀 | 含义 | 示例 |
|---|---|---|
| `B###` | 基线模型 | `B001-AARF.py`, `B002-KmerLR.py` |
| `B###a` | 基线衍生方法 | `B003a-cnn-threshopt.py` |
| `C###` | CNN 相关模型研究 | `C001-cnn.py` |
| `T###` | Transformer 相关模型研究 | `T001-rope.py` |
| `TC###` | Transformer + CNN 集成 | `TC003-ensemble.py` |
| `CK###` | CNN + k-mer 相似性特征集成 | `CK001-ensemble.py` |
| `TCK###` | Transformer + CNN + k-mer 集成 | `TCK001-ensemble.py` |
| `R###` | RNN 相关模型研究（含其表示应用） | `R001-BiLSTM.py`, `R002-feature-embedding.py` |
| `E###` | 预训练嵌入研究 | `E001-pretrained-neighbor.py` |
| `I###` | 集成方法研究（分类器/级联/门控） | `I001-classifier-comparison.py` |
| 无编号 | 工具 / EDA 脚本 | `eda.py`, `main.py` |

命名格式：`{编号}-{结构/特征缩写}.py`，编号（大写）统一写在最前面。

### 模型文件
| 格式 | 适用场景 | 示例 |
|---|---|---|
| `.joblib` | sklearn 模型 | `models/basl-KmerLR.joblib` |
| `.pt` | PyTorch 模型 | `models/cnn-onehot.pt` |

模型文件名与脚本描述段对应（不含编号前缀），脚本内 `MODEL_PATH` 常量指向。

### 输出文件
| 类型 | 命名格式 | 示例 |
|---|---|---|
| 提交文件 | `submit/submission_{缩写}.csv` | `submission_AARF.csv` |
| 验证指标 | `rel/{缩写}_val_metrics.json` | `AARF_val_metrics.json` |
| 验证预测 | `rel/{缩写}_val_pred.csv` | `AARF_val_pred.csv` |

### EDA 图表
`rel/{序号}_{描述}.png`，序号从 01 起递增。

## 代码规范

1. 每个实验方法写**单独 `.py` 文件**，可独立运行
2. 脚本头部使用 docstring 说明：模型概述、特征、策略、输出文件、引用文献
3. 常量集中定义在文件顶部，使用大写命名
4. 使用与 `basl-AARF.py` 相同的 `VAL_SIZE=0.2` 和 `RANDOM_STATE=42` 以保证可复现
5. 输出统一为：提交 CSV + 验证指标 JSON，可选模型文件
6. 训练完成后自动保存模型到 `models/`
7. 禁止硬编码绝对路径，使用相对路径
8. **所有循环型耗时段（逐标签训练/推理、阈值搜索、网格扫描、epoch 循环等）默认加 tqdm 进度条**（2026-08-15 起强制）

## 提交文件格式

CSV，列顺序：`protein_id, label_0, label_1, ..., label_499`
- `protein_id`：与测试集一致
- `label_X`：整数 0 或 1
