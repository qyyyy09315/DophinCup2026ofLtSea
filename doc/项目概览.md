## 一、项目定位

**2026 第三届大学生海豚杯数智应用创新大赛 · 分析赛**参赛工程，任务为**多标签蛋白质功能预测**：仅输入氨基酸序列，预测 500 个匿名功能标签（`label_0` ~ `label_499`）的多标签 0/1 向量。

- 队伍：**点燃大海（Light The Sea）**；负责人 Yue-xin GENG（GitHub `qyyyy09315`），成员 Shu XU、Si-yang LIU、Jiao-nei WU；受 Hong-xi TAO 邀请参赛。
- 赛制：提交结果自动评分占 **70%**，大数据分析报告专家评审占 **30%**；每天最多 3 次提交；最终排名以私有榜（70% 测试数据）为准；比赛结束 2026-11-15。
- 评分函数：**Macro F1**（逐标签 F1 算术平均，跳过无正样本标签）。
- 硬约束：**禁止外部数据**；允许使用 ESM / ProtBERT 等预训练模型；赛后前三名需提交可运行代码。

## 四、核心架构：融合链

当前有效方法（`I065`，9.18）与 README 所记（`C011a`，8.28）已有代差——**README 的融合链描述停留在 C011a 时代**。

```
蛋白质序列
  ├── deep 分支：RoFormer(T001a/T002) + CNN(C002b×C005) + PLM-MLP(1664D 多种子)
  └── sim  分支：0.4·DIAMOND bitscore(top-3) + 0.6·多 k k-mer(k=3~8, k6 主导, sim² 加权)
        ↓  2-hop 同源传递（拯救 22.8% 孤儿序列）
        ↓  分支线性混权（I064：PLM 支 w=0.35；RRF 用于 PLM 支劣于线性）
        ↓  I011 实例内 RRF：1/(30+rank_deep) + 1/(30+rank_sim)
        ↓  I019 Sinkhorn 双边匹配：τ=0.20, ρ=1.0, α=0.60
        ↓  SCut 逐标签 100 档阈值（目标 Macro F1）
     0/1 提交 CSV
```

**关键设计约束（多处已"锁"，禁止随意改）**：val 邻居只从 `idx_train` 建；RRF 公式锁 `1/(k+rank)`、k 锁 30、β 锁 0.50；Sinkhorn 锁在 I011 融合之后；比对权锁 bitscore；`SIM_W` 锁 0.75、`ALIGN_W` 锁 0.4；阈值目标锁 F1；Sinkhorn τ 锁全局 0.20。

**有效门槛**：融合 Macro F1 相对当前锁 ≥ **+0.001** 才算有效，否则结论必须写"关闭 / 无增益"。

## 十、一句话总结

这是一个**以实验编号体系为骨架、以"关闭轴"为知识资产**的竞赛工程：269 个脚本按 9 个语义系列组织，通过共享缓存与 `load_module` 跨目录调用串成"多路深度 + 同源比对 + RRF + Sinkhorn"的融合链，已把模型侧 12 条改进轴逐条实测关闭并沉淀为 3,800 行实验日志 + 240 条文献 + 三份报告；当前瓶颈不在方法而在**模型判别力**（低 FPR 区 TPR 缺口 0.22），提交侧与报告侧是剩余期望值最高的两个方向。
