## 一、立项逻辑：两条线 + 一个突围假设

### 1.1 为什么头容量是下一个死穴（I 线）

- **历史死穴**：PLM-MLP 头 = 3 层平坦 MLP，仅逐标签独立线性投影，**无法建模标签条件共现与高阶
  相互作用**（500 标签全稠密、均值基数 25.4，共现结构是真实存在的信号，平坦头完全丢弃）。
- **I096 已证**：同等结构下 80ep 充分收敛即可 +0.0407，说明此前的瓶颈一半在训练预算；结构容量是
  下一个同量级的自由度。I096 脚本中 **DeepSwiGLUNet（SwiGLU 门控 ResNet）已定义未启用**，是现成资产。
- **文献支撑**：[242] ML-Decoder 证明 grouped-query 交叉注意力头在大规模多标签（10k 类）上
  全面优于逐类线性头；[243] SwiGLU 是 Llama 系同款门控块；ATGO（Bioinformatics 2022）证明
  ESM 嵌入 + 注意力头在功能预测上有效（生物域先例）。

### 1.2 为什么 G 系列值得复活而非废弃（G 线）

G001~G006 全关闭，但关闭原因是**联合分布**：浅生成器（35ep 头时代预算）× 弱下游头（独立仅
0.26 左右）× 无物理约束（C2ST 放行率 0%~11%）。三个因子任何一个改善都可能翻转结论：

| 因子 | G 系列当时 | 本轮改变 |
|---|---|---|
| 下游头强度 | 35ep 浅头，独立 0.26 左右 | **I096 收敛头协议（80ep+早停，独立 0.3036）**——弱头下被淹没的合成信号可能在强头下显影（G004 结论原话："合成样本在 35 epoch 浅层 MLP 下未能转化"） |
| 生成器预算 | 单一短训，无早停选点 | **迭代轮数扩展 + C2ST 放行率监控早停**（择优保存） |
| 约束注入 | 仅标签条件 y | **物理/生物描述符条件化 + 分布匹配正则 + 双门控**（[244] Chroma"约束即贝叶斯推断"、[245] 能量引导 FM） |

### 1.3 突围假设（明确可证伪）

> **H-A（头）**：标签感知结构头（共现/交互建模）改变的是**误差结构**而非单纯强度，
> 因此可以在融合层传导——区别于 I096 的"同结构加轮数"。
> **H-B（生成）**：合成样本的下游增益 = f(生成保真度 × 头容量)。保真度（C2ST 放行率）与
> 头容量（I096 协议）双双提升后，G 线的 ΔOOF 从 +0.0002 量级显著抬升。
> 证伪条件：若 I098/I099 独立涨而融合 ΔOOF < +0.001，法则第 7 次确认，I 线转 **I101 新支路方案**
> （见 3.6）；若 G007/G008 放行率提升后 ΔOOF 仍 ≤ +0.0005，G 线终局关闭（含强头条件）。

## 二、编号规划总览

```
I 线（大容量最终分类器）
├── I098  Deep-SwiGLU-ResNet 收敛头（现成代码启用，80ep+SCut早停，对照 I096 同预算）
```

## 三、各编号详细技术方案

### I098 — Deep-SwiGLU-ResNet 收敛头

- **定位**：最小改动的大容量头。`code/I/I096-converged-plm-head.py` 已内置 `SwiGLUBlock` +
  `DeepSwiGLUNet`（hidden=1536，4 blocks，SwiGLU hidden_dim=2304，dropout 0.2，残差 + LayerNorm），
  当年仅作探针定义、main 未启用。
- **训练协议**：与 I096 严格同预算——1664D 特征、ASL、AdamW lr=1e-3 wd=1e-4、cosine T_max=80、
  batch 512、**80ep + 逐轮 val SCut 搜索早停（patience=10）**、seed=42。tqdm 单行日志。
- **参数量与预算**：约 45M（vs 平坦 MLP 约 3M，×15）。RTX 4060 fp16 估算 **10~15 min**。
- **判据**：Gate 1 独立 SCut F1 > **0.3036**（I096 新锚点）；Gate 2 融合 OOF ≥ **0.4396**（0.4386+0.001）。
- **关闭条件**：训练不稳定（loss 发散/显存超限）降 hidden=1024 重试一次，仍不稳关闭；
  独立 ≤ 0.3036 直接关闭（不再走 Gate 2）。

### I099 — ML-Decoder 分组查询注意力头（[242]）

- **定位**：多标签专有结构，正面回答"标签共现建模"死穴。
- **架构**（500 标签、1664D 输入、8GB 显存约束下的落地版）：
  1. 标签嵌入 $E \in \mathbb{R}^{500 \times d}$（$d=128$，可学习，随机初始化）——500 类各持身份向量，
     self-attention 层在嵌入间传递共现模式（替代禁用的 GO 层级图，用数据学共现）；
  2. **grouped query**：500 标签分 $G=25$ 组（每组 20 类），组内共享 query 向量做对 1664D 特征
     （投影为 K/V，$d_k=128$）的交叉注意力 → 计算量 $O(G \cdot d^2 + L \cdot d)$，避免 500×500
     全查询的显存压力；组间嵌入再过 1 层轻量 self-attention（L²=250k 注意力矩阵，fp16 可承受）；
  3. 每标签线性分类头（标签嵌入 → logit）。
- **训练协议**：同 I096/80ep/ASL/cosine/早停。ASL 对注意力头同样适用（判据不变）。
- **预算**：约 15~20 min。
- **判据 / 关闭条件**：同 I098；若注意力层梯度异常（norm 爆炸），退化为「标签嵌入 + MLP 头」
  消融刀再测一次，仍不行关闭。

### I100 — 最优头多种子 + 全量重训出提交

- **前置**：I098/I099 至少一个过 Gate 2（换锁）才启动。
- **方案**：胜出头结构 seeds=[11,22,33] 三种子 80ep（80% 训练）→ 融合样内/OOF 复核换锁；
  再 100% 全量重训（周志华交付原则，I097 同款流程：阈值校准参考须用同结构头的 val 概率，
  **不得沿用 i096 MLP 的校准文件**）→ 生成 `submission_I1XX_fulltrain_80ep.csv`。
- **预算**：3×单卡时（约 1h 量级，视头结构）。

### I101 —（备选突围）新头作为第 6 路 deep 支

- **触发**：I098/I099 独立涨、融合不传导（法则第 7 次）时启动。
- **方案**：不替换 PLM 支，把新头概率作为**独立第 6 路**进入融合：先逐路 rank 归一后线性混权
  网格（含 0 做对照），或 1/(30+rank) RRF 注入（I064 的 `use_rrf_plm` 机制扩展为 `use_rrf_head6`）。
  假设：新支路与现有 5 路的**误差相关性**足够低（新结构、新归纳偏置），秩融合才有正增益——
  这是对"信息集合"的扩展，而非对"同源支强度"的替换。
- **判据**：融合 OOF ≥ 0.4396；关闭条件：全网格 ≤ 0.4386+0.0005 终局关闭 I 线。

### G007 — 流匹配 × 迭代轮数 × 早停 × 收敛头（G 线复活主刀）

- **方案**：严格沿用 G004 配方（1664D、条件速度场 $v_\theta(x_t,t,y)$、20 步欧拉 ODE、
  靶向基数 ≤10 标签、合成 K=3000），仅改两处：
  1. **生成器迭代轮数 ×5**（步数上限提高，含 batch 轮换充分训练）；
  2. **生成早停/择优**：每 500 步做一次 C2ST 严格区间放行率评估，以放行率为监控指标保存最优
     检查点（patience 机制），杜绝"过训导致流形外推"与"欠训保真不足"两头失败。
- **下游**：合成样本注入后训练 **I096 收敛头（80ep+早停）**，不再用 35ep 浅头。
- **判据**：中间指标 C2ST 严格放行率 > 11%（G004 记录）；端到端 Gate 1 独立 > 0.3036、
  Gate 2 融合 OOF ≥ 0.4396。
- **预算**：生成 10~15 min + 收敛头 10 min ≈ **25 min**。

### G008 — 物理/生物约束三通道注入（本轮 G 线核心创新）

- **约束来源（可计算描述符，全部来自序列本身，不违反禁外部注释库）**：
  氨基酸组成 20 维、净电荷/pI、Kyte-Dohittle 平均疏水性、分子量、长度、低复杂度区比例、
  3/6-mer 频率谱（归一化），共约 50 维描述符向量 $c$。真实样本描述符从 `train.fasta` 现算并缓存。
- **关键技术约束（必须写明）**：ESM2 是 encoder-only、**无 decoder**——"生成特征→解码序列→
  物理校验"链路不存在。物理约束只能以**辅助信息通道**形式注入潜空间，具体三通道：
  1. **条件通道**：$G(z, y, c)$——目标描述符从真实孤儿/低基数切片的描述符分布采样，
     生成器学习"给定物理画像 + 标签 → 特征"的条件映射；
  2. **辅助回归判别器**：$D(x, y)$ 除真伪头外加物理回归头 $\hat c=\phi(x)$，
     损失加 $\lambda_{\text{phys}}\|D_{\text{phys}}(x_{\text{real}})-c_{\text{real}}\|^2$ 与对合成样本的
     $\|D_{\text{phys}}(G(\cdot))-c\|^2$（[244] Chroma"约束即贝叶斯推断"、[245] 能量引导 FM 的落地版）；
  3. **分布匹配正则**：生成批与真实批的描述符 MMD（中位数启发带宽）作第三项损失。
- **双门控**：C2ST 严格区间放行 ∩ 描述符逐维 KS 检验（p>0.05 维度占比 ≥ 60%）。
- **下游与判据**：同 G007（收敛头 + 双门槛）；关闭条件：放行率仍 < 11% 或 ΔOOF ≤ +0.0005 终局关闭。
- **预算**：**约 30 min**。

### G009 —（备选生成器）OT-CFM 条件最优传输流匹配

- **触发**：G007/G008 均未过线但 C2ST 放行率显示"路径质量"仍是瓶颈时启动。
- **方案**：G004 的独立高斯 → 数据直线路径替换为 **mini-batch OT 配对路径**
  （每 batch 内 Sinkhorn 求最优配对再线性插值，I019 已有 sinkhorn 实现可复用），
  生成轨迹更贴数据流形，预期放行率进一步抬升；[246] TabDDPM（Gaussian 扩散 + 分类条件）
  作为同级备选实现，二选一实测。
- **判据**：放行率 > 30% 且双门槛同上；预算约 30 min。

## 四、守卫原则与风险（防伪增益）

1. **靶向切片原则不变**：扩增严格限定孤儿切片（同源为 0，1,748 条）与低基数标签，
   禁止全量无差别过采样（I092 铁律）。
2. **双门槛验收不变**：独立门槛更新为 **> 0.3036**（I096 新锚）；融合换锁线 **OOF ≥ 0.4396**。
3. **消融边界**：每刀只改一个变量（头结构 / 生成步数 / 约束通道），跨刀组合前先单刀过线。
4. **校准同源原则**：I100 出提交时，阈值校准参考必须来自**同结构头**的 val 概率
   （I097 教训：35ep 参考与 78ep 收敛头阈值 mean|Δ|≈0.071，混用即失准）。
5. **主要风险**：
   - 不传导法则第 7 次（概率不低）→ I101 新支路兜底，I 线不完全沉没；
   - SwiGLU 头 45M 参数在 91k 样本上过拟合 → dropout 0.2 + wd + SCut 早停三重防护；
   - 生成器加轮数可能加剧判别器过拟合 → 放行率早停择优 + 判别器梯度正则；
   - 物理描述符与 PLM 特征相关性弱（ECK009/ECK010 先例：物化通道独立弱）→ G008 的价值在
     **约束生成质量**而非描述符本身预测力，门控指标以 C2ST 为主、KS 为辅。
