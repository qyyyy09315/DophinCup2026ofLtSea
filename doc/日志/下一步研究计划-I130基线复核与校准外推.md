## 冻结协议与执行

分析性实验，不占 I150 编号、不生成提交、不操作腾讯文档。入口 `code/tools/audit_i130_calibration.py`，输出独立目录 `rel/i130_calibration_audit_20261012/`，CPU 预算≤15分钟。

1. 用 I130/I144 原有概率、邻居和图缓存重建固定 Penta/Hexa 配方，数值 helper 不改。复算同集 F1 必须在 JSON 舍入误差0.00001内复现，否则停止比较。
2. 原验证集内5折（shuffle，seed=20261012），每轮4折校准、1折评分。两个 SCut 阶段只访问校准标签，train80 标签先验冻结。
3. 保留无标签全验证批次、RRF 列归一化和转导图；评分标签只用于指标计算。
4. 拼接所有留出决策，计算总体 Macro F1，并报告各折 F1/Precision/Recall/Macro AUC/microAUC。折之间相关，不将胜率等同显著性。
5. CMAT 当前固定配方候选门槛：总体F1 Δ≥+0.001且至少4/5折为正。未过线不追加该配方训练。

## 比较边界

模型/缓存/超参此前已按整个验证集选择。本轮只诊断固定模型下的阈值外推和两级校准乐观差，不宣称完全独立的全模型 OOF。严格模型外推评估需重训所有分支、重建各折邻居和独立校准，不能用本轮替代。
