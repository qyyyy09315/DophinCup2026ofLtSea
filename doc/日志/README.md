## 填写规则（所有日志共通）

1. **只追加，不改已有段落。** 纠错另起「更正（日期）」短段，不要改历史数字。
2. **按日分节。** 当日已有 `## YYYY-MM-DD` 就在该节末追加；没有就新建日期节。不要把 08-22 的实验写进 08-21 节。
3. **一条记录一个主题。** 文献一轮、实验一个编号、过程一次变更，不要混写。
4. **指标从 JSON 抄。** Recall / Precision / AUC / Macro F1 四位小数；口径与提交一致（100 档阈值除非写明 0.5）。
5. **有效门槛。** 全局 Macro F1 相对当前锁（现为 **C011a** 半折 OOF）≥ +0.001 才算有效；独立 CNN 对照 C002b F1(0.5)=0.2714。否则结论写「关闭 / 无增益」。
6. **分析性实验**写实验日志，**不写腾讯表格**（在条目里注明「分析性，不写表格」）。
7. **腾讯表格**只追加：编号、方法、四指标、备注（方法+1～2 参数+结论，不写提交/推荐）、代码文件、qy、`YY.M.D`、文献短引用。规则权威版：`doc/实验规则.md`。
8. **三处同步文献**（有新引用时）：脚本 docstring → 腾讯表格「参考文献/资料」→ `参考文献.md` 新编号。
9. **完成后**把 `待办.md` 对应未完成项整行移到已完成，补半句结果。
10. **中文。** 编号、文件名、指标保持原样。

## 各文件模板

### 实验日志（正式实验）

```
**{编号} 完成（YYYY-MM-DD，有效|负结果|分析性）**
- 一句话方案 + 关键参数
- 指标：F1 / R / P / AUC（相对谁 ±）
- 结论：有效并替换 X / 关闭某轴 / 不替换当前最佳
- 文件：`code/...`；报告 `rel/{编号}_report.json`
```

派生编号用小写字母后缀（CK005a），禁止 `CK005-xxx` 连字符变体。

### 文献调研（新一轮）

```
### 文献调研（YYYY-MM-DD，第 N 轮：主题）
约束：……
**筛过 / 不投入**（表或列表，给原因）
**可落地**（至多 1～2 个，给编号建议）
**下一步**：唯一推荐的实验编号 + 一句话判据
```

不要在这一节粘贴实验完成指标。落地后去写实验日志。

### 参考文献（新条目）

```
**[n] 方法名** — 一句话用途
- 引用格式：作者. 标题. 期刊/会议, 年.
- 链接：https://doi.org/… 或 https://arxiv.org/abs/…
- 应用实验：编号（做了什么）
```

`n` = 当前最大编号 + 1。已有条目只可在「应用实验」行追加编号，不改引用正文。

### 过程纪要

```
### {变更名}（YYYY-MM-DD）
- 改了什么（环境 / 规则 / 路径 / 工具）
- 写进了哪份规范（实验规则 / 文件规范 / 代码索引）
```

### 待办

- 未完成：`- [ ] 短句`（能直接变成一个编号实验或文档任务）
- 完成：把该行移到已完成，改成 `- [x] …：结果`

## 实验完成后的最小写入集

| 动作 | 目标 |
|---|---|

| 勾待办 | `待办.md` |
