### I082 同源支头部漏检证据分解（决定 top-100 go/no-go）

对 sim 支 255,142 个漏检格（真实正例、分数低于逐标签阈值）按证据结构分解：

| 类别 | 占比 | 含义 | 对策 |
|---|---|---|---|
| A 孤儿（无命中） | 8.56% | 无比对证据 | 已由 2-hop 部分覆盖 |
| B 证据闲置（第 4-5 命中携带标签） | 12.45% | 聚合没用上缓存 | tk=5 实测融合 +0.0000，**免费但无效** |
| C 证据已用（top-3 携带仍漏） | 28.21% | 校准/聚合问题，top-100 无用 | 无直接对策 |
| **D 证据缺失（top-5 都不带标签）** | **50.78%** | 只有更深检索才可能救 | **top-100 重跑是唯一杠杆** |

判定：**GO（有条件）**——D 类占一半，top-100 是仅剩的检索深度杠杆；
但 tk=5 零增益提示聚合器已饱和，**top-100 的聚合必须加门控**（bitscore 档位或截断），
否则重演 CK005k 的弱同源噪声（覆盖涨、F1 不涨）。

### 3. I084 650M 嵌入评估（提取完成后由助手执行，分钟级）

- MLP 头输入 1664D → **2944D**（640+1024+1280）与 **5504D**（last3 拼接变体）对照
- 判据 = 融合 Macro F1（三件套照旧）；**通过线：融合 ≥ 0.4485（+0.001）才进提交**，否则记录负结果关闭
- 预期依据：I060 的先例（加预训练 PLM 特征是唯一成功过的分支扩展）；I076（融合增益跟随绝对强度）
- 风险：650M 与 150M 同族同语料，误差相关性可能偏高（I062 教训）

### 4. DIAMOND top-100 手动重跑（用户手动，4 张表；I084 通过后再决定是否值得）

```bash
./tools/diamond/diamond blastp -q <query.fasta> -d <db> -o <out.tsv> \
  --very-sensitive -e 0.001 --max-target-seqs 100 --outfmt 6 qseqid sseqid bitscore evalue
```

需要：train→train（现有 c014 版仅 top-5 等价物）、val→train、test→train、test→test。
聚合方案先定再跑：top-20 + bitscore 门控（如累计 bitscore 占比 ≥ 阈值），
预期目标仅 D 类 50.8% 的漏检格，理论上限可观但受 CK005k 噪声教训约束。
