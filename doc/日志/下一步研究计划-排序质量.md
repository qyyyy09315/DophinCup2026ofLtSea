## 一、缺口的精确定位（已完成，不必再查）

I072 用逐标签 ROC 在 FPR 从 0.02 扫到 0.10，把缺口钉死在一处：

| 分路 | AUC | pAUC[0,.1] | R@FPR0.02 | R@FPR0.05 | **R@FPR0.069** |
|---|---|---|---|---|---|
| PLM-MLP 1664D | 0.7947 | 0.3259 | 0.2328 | 0.3520 | 0.4063 |
| Deep-5 路（含 PLM） | 0.8220 | 0.3625 | 0.2586 | 0.3932 | 0.4517 |
| Sim（比对+2hop+kmer） | 0.7786 | 0.4552 | 0.4111 | 0.5153 | 0.5472 |
| RRF 融合 | 0.8646 | 0.5133 | 0.4322 | 0.5563 | **0.6026** |
| 最终（+Sinkhorn） | 0.8647 | 0.5119 | 0.4313 | 0.5563 | 0.6026 |

三条硬结论：

1. **缺口在排序头部，不在决策层、不在融合层。** 榜首在同一 FPR（0.069）处召回约 0.82，我方 0.6026，差 0.22 全部落在模型判别力上。
2. **Sim 分路是头部专家**：AUC 最低（0.7786）但 R@FPR0.069 最高（0.5472），比 Deep-5 路高 +0.0955。「全局 AUC 高」与「头部召回高」是两种能力，不可互推。
3. **Sinkhorn 对头部零贡献**（0.6026 → 0.6026）。它只修正基数与列边际，不改善排序。

### 补充：标签分布核实（2026-09-18，影响后续判断框架）

| 指标 | 训练切分（91,036 条）逐标签正例数 |
|---|---|
| 最小 | **1,025**（流行率约 1.13%） |
| 1% / 5% 分位 | 1,037 / 1,105 |
| 中位 | 2,162 |
| 最大 | 59,612（流行率约 65%） |
| 正例数 <5 / <10 / ==1 的标签数 | **0 / 0 / 0** |

**500 个标签全部稠密，最少也有 1,025 个正例**（验证切分中至少约 256 个）。本任务**不存在稀有类/空标签问题**，
标签集明显经过组织方平衡。三项推论：

1. 文献中所有「长尾 / 稀有类处理」类方法（含 EZpred 的「别丢稀有类」行动项）**在本任务不适用**，不必投入。
2. 逐标签阈值调优不受小样本过拟合威胁（每标签验证集正例 ≥256），NTU 论文警告的「稀有标签阈值过拟合」不成立
   ——但这对提分也无帮助（阈值不改变纯排序指标）。
3. Macro F1 对 500 个等权标签取平均，**没有「注定零分」的标签**（I076 实测零分标签数为 0）。
   这也解释了 I075/I076 中频率分带差异相对温和——「极稀有」带其实是 1.13%~2.1% 流行率，远比真实 GO 术语稠密。

| 熵最小化自训练 | **有直接反向证据** | Wu et al., *Multi-Label Test-Time Adaptation with Bound Entropy Minimization*, ICLR 2025, arXiv:2502.03777，Prop. 1：传统熵最小化不适用于多标签，只会抬高最自信标签而忽略其他正类 |

| 纯伪标签自训练 | **关闭** | Arazo et al., IJCNN 2020, DOI 10.1109/IJCNN48605.2020.9207304（确认偏差，被引 687）；多标签下需显式类别分布矫正才能工作（Xie et al., NeurIPS 2023） |
| 检索式 kNN 新增分支 | **信息同源** | Protriever（Weitzman et al., ICML 2025, arXiv:2506.08954）的检索空间用 **BLAST 同源性作 DPR 监督**训练出来——检索空间与 DIAMOND 不是两类信息，而是同一类（进化相关性）的两种实现 |

**理论解释**：Krogh & Vedelsby, NIPS 1994, pp.231-238 的歧义分解 `E_ens = Ē − Ā`——集成收益是零和权衡，不是免费午餐。Brown & Kuncheva, MCS 2010, DOI 10.1007/978-3-642-12127-2_13 进一步区分 good/bad diversity：**多样性只有在与集成自身误差不相关时才降低集成误差**。

**必须同时记住的反向警告**：Kuncheva & Whitaker, *Machine Learning* 51(2):181-207 (2003), DOI 10.1023/A:1022859003006 系统评估 10 种多样性度量，结论是**多数通用多样性度量与集成精度相关性很弱**。I075 节 3 实测复现了这条警告——我们自己的两两头部一致性 vs 融合增益 r = +0.7972，但弱支 F1 的混淆项 r = +0.4368，二元拟合后符号方向与去相关法则相反，**不能作为设计依据**。唯一干净的证据是受控对照（I075 节 4）。

## 三、I075–I077 交付的结论：为什么不能靠"改进分支"拿分

后续所有候选分支必须**三件套同时报告**：

1. 独立指标：F1 / AP / R@FPR0.069
2. 与现有分支的头部预测集合 Jaccard（变化集中在头部集合，全局相关系数不敏感）
3. **融合后的 Macro F1**

**判据只能以 ③ 为准。** ② 只作诊断，**不能用作准入门槛**——下面的实测数据否否决了把它当门槛的做法。

### 实证依据

**I075 节 4（受控：同种子 42、同架构、仅损失不同）**——冗余确实在头部上升：

| 指标 | plm_asl | plm_prop |
|---|---|---|
| 独立 F1 / AP / R@FPR0.069 | 0.2638 / 0.2096 / 0.3897 | 0.2724 / 0.2167 / 0.4004 |
| 与 sim 头部集合 Jaccard | 0.1374 | **0.1469 ↑** |
| 与 集成(deep4+sim) Jaccard | 0.1685 | **0.1809 ↑** |
| 与 sim 配对融合 F1 | **0.4387** | 0.4375 ↓ |
| 与 集成全样本相关 | 0.5347 | 0.5280（几乎不变）|

**但 I076 在标签级否决了「冗余解释」**（n=500）：

| 相关性 | 期望符号 | 实测 |
|---|---|---|
| `dF1_l` vs 头部假阳性重叠 `overlap_l` | 负 | **+0.3014（符号相反）** |
| `dF1_l` vs 正例秩相关 `rho_l` | 负 | −0.1273（符号对，但仅解释约 1.6% 方差）|

**并且频率分带的走向与去相关法则相反**：

| 频带 | n | sim F1 | deep5 F1 | **dF1** | overlap |
|---|---|---|---|---|---|
| 极稀有 <Q1 | 125 | 0.4107 | 0.2477 | +0.0113 | **0.1140（冗余最低）** |
| 稀有 Q1-Q2 | 125 | 0.4008 | 0.2426 | +0.0100 | 0.1344 |
| 中等 Q2-Q3 | 125 | 0.4202 | 0.2851 | +0.0178 | 0.1623 |
| 高频 >Q3 | 125 | 0.4947 | 0.4094 | **+0.0211（增益最高）** | **0.1915（冗余最高）** |

**增益与冗余同向上升**——融合增益由**分支绝对强度**驱动，不由去相关驱动。

**I077 又否决了「标定错位」解释**：倾向加权的代价在每一种标定方案下**精确等于 −0.0007**
（原始分 −0.0007 / min-max −0.0007），说明与分数尺度无关。

三个附带工程结论（不必再试）：

- **现有原始分线性混合已是最优注入形式**：min-max 标定损失 0.0055、z-score 损失 0.1063、RRF 秩融合损失 0.0188。**不要再改融合层的标定方式。**
- z-score 失效原因：它把逐标签分数中心化到 0，使 Sinkhorn 核的**逐行** rowmax 失去跨标签可比性，传输计划被破坏。
- 单种子 I073 头（0.4471）比 3 种子集成（0.4475）略低，符合预期。

### 统一结论

**融合结果对单个分支的依赖不是该分支独立质量的单调函数。** 我们试过的所有解释度量（全局相关系数、头部集合 Jaccard、标签级 overlap 与 rho、分数标定）**都无法预测它**。这与文献警告一致：Kuncheva & Whitaker, *Machine Learning* 51(2):181-207 (2003), DOI 10.1023/A:1022859003006 系统评估 10 种多样性度量，结论是多数度量与集成精度相关性很弱。

**工程含义（本节最重要的产出）**：不要再投入"提升单个分支"。资源应投向改变**信息集合**或**融合层目标函数**的方向——即下面的路线 A / B / C。

## 四、三条在研路线

### 路线 A（首选）— 同源分支的可学习条件化聚合  **已关闭（I078）**

**动机**：我方 sim 支 = DIAMOND bitscore 加权 + k-mer 加权求和，这是**人为固定的聚合器**。文献中最强的同源检索方法全部把聚合器换成**学习出来的、以（查询 × 候选标签 × 正负 exemplar）为条件**的打分器。

**文献依据（已核实）**

- ProtEx（Shaw et al., Google DeepMind, bioRxiv 10.1101/2024.05.30.596539）：检索用 BLAST 训练集内 **top-100**；对每个候选标签取 k_p 个正 exemplar + k_n 个负 exemplar；T5 encoder-decoder 输出 p/n 二分类；**SOTA on EC / GO / Pfam，且增益在稀有类与远离训练集的序列上最显著**；支持零样本迁移到未见标签。
- ProtIR（Zhang et al., arXiv:2402.07955）：retriever 与 predictor 用变分伪似然 **EM 式互相迭代精炼**，核函数 `K = exp(cos/τ)` 取 **τ = 0.03**，**5 轮内收敛**；相对无预训练 predictor +10%，但最终水平是与 PLM 类方法持平。注意其检索集合是**有标注集**，未用 test-test 边。
- InterLabelGO+（Liu, Zhang, Freddolino, *Bioinformatics* 40(11):btae655, 2024, DOI 10.1093/bioinformatics/btae655）：与我最接近的已发表架构（ESM2 末三层多头网络 + AlignmentKNN，动态加权），CAFA5 顶级方法之一。但它**没有报告分支间误差相关性，也未论证多样性 vs 强度的权衡**。

**为什么它不落入「同信息分支」的三连负结果**：它不是新增一支同信息分支，而是**替换 sim 支内部固定的人为聚合规则**。条件化打分器能表达「针对这条查询的这个标签，该不该信这次命中」这种逐对逻辑，而固定加权求和表达不了。

**设计 J076**

- 形态：条件化重排头，**冻结 A/B 两支**，只在融合分之上重排
- 输入：`[query ESM2 嵌入的降维分量 ⊕ 标签频率 ⊕ 该标签在 top-k 命中中的加权命中率 ⊕ 最高 bitscore ⊕ k-mer 分 ⊕ 该标签的 DIAMOND 命中数 ⊕ 融合分]`
- 训练：现有 train 的 0/1 标签 + ASL，35 epoch 量级
- 数据缺口：现有 DIAMOND 只保留 **top-5**（E≤0.001），ProtEx 用 top-100。→ **需重跑 DIAMOND 保留 top-100（手动长训项）**
- 首轮验证：先用现有 top-5 做概念验证，同时排队 DIAMOND 重跑
- 验收：三件套 + 止损条件（R@FPR0.069 不升、或融合 Macro F1 下降 → 关闭）

### 路线 B — 转导式标签传播作为第三支  **已关闭（I079）**

**动机**：这是**唯一可能有新信息**的路线。A 支用单序列嵌入（无图结构），B 支用 DIAMOND 局部比对（E≤0.001 强同源）。ESM2 嵌入图上的 kNN 抓的是**全局相似性结构**，与被 E 值截断的比对命中误差结构不同，且与两支都不共享信息来源。

**文献依据（已核实）**

- Zhou, Bousquet, Lal, Weston, Schölkopf, *Learning with Local and Global Consistency*, NIPS 2003：标准形式 `S = D^{-1/2} W D^{-1/2}`，迭代 `F ← αSF + (1-α)Y`，α∈(0,1)，kNN 的 k = 10~30，边权 `w_ij = exp(-‖x_i-x_j‖²/2σ²)`，10~50 次迭代至收敛。
- ZLaP（Stojnić, Kalantidis, Tolias, CVPR 2024, arXiv:2404.04072）的**测地距离**可缓解 hubness。**注意：这是视觉-语言零样本分类论文，不是蛋白质论文**，方法可迁移但不能按 PFP 文献引用。

**文献警告与必做对照**

- 检索确认：**没有任何一篇 PFP 论文做过「test-test 边 vs test-train 边」的受控消融**——这是真实文献空白。因此本路线的判断依据部分来自机制推理，不是文献结论。
- **必做反例测试**：把测试集从图中移除（只用训练集构图），若效果相同 → 收益来自 kNN 检索而非转导信息 → 立即放弃。
- Macro F1 特有风险：图平滑会把稀有类分数拉向邻域多数类，而 Macro F1 对稀有类极敏感。
- 逐标签归一化传播分（z-score），否则高频标签淹没低频标签。

**设计 J078**：ESM2 嵌入 + FAISS kNN 构图 → 标准 label spreading → 逐标签 z-score → 作为第三支进 RRF（`w_LP` 从 0.7 起，因 LP 未经判别训练、分数尺度不同）。α 在 `{0.2, 0.5, 0.8, 0.9, 0.99}` 中按验证集 Macro F1 选。

**不要混入 DIAMOND 比对图**——那是 B 支已用的信息源，混入会重新引入相关性。

### 路线 C — 只对重排头施加 pAUC 头部目标  **已关闭（I080）**

**前提**：路线 A 的重排头先立住。**绝对不要同时对 A、B 两支施加**——会把两支头部排序推向同一形状，直接重演负结果。

**文献依据（已核实，含官方文档逐字超参）**

- Zhu et al., *When AUC meets DRO: Optimizing Partial AUC for Deep Learning with Non-Convex Convergence Guarantee*, ICML 2022, PMLR 162:27548-27573（pAUC-DRO / SOPAs）
- Qi et al., *Stochastic Optimization of Areas Under Precision-Recall Curves with Provable Convergence*, NeurIPS 34:1752-1765 (2021), arXiv:2104.08736（APLoss + SOAP）
- Yuan et al., *LibAUC: A Deep Learning Library for X-Risk Optimization*, KDD 2023, DOI 10.1145/3580305.3599861

**LibAUC 官方配方**（来自 `docs.libauc.org`，逐字核实）：

```
阶段一（预训练）：BCELoss + Adam(lr=1e-3, weight_decay=2e-4)，60 epoch，[30,45] 处 lr×0.1
阶段二（pAUC 微调）：加载阶段一权重，但丢弃并重置最后一层 fc
  MultiLabelpAUCLoss(data_len, margin=0.6, gamma=0.1, beta=0.07)   # 建议用 MultiLabelpAUCLoss
  SOPAs(mode='adam', lr=1e-3, weight_decay=2e-4)
  DualSampler(trainSet, batch_size=64, sampling_rate=0.5)          # 正:负 = 1:1
  [30,45] 处 update_lr(decay_factor=10)
超参网格：gamma ∈ {0.1, 0.3, 0.5, 0.7, 0.9}，margin ∈ {0.6, 0.8, 1.0}
```

- **`beta` 就是 pAUC 区域的 FPR 上界，直接设 0.07 对齐我方诊断点**（不要用教程默认 0.3，那会优化到远离我们关心的区域）。
- 官方通用提示（原文）：复杂任务应先用常规损失预训练，再切 AUCMLoss 用**更小学习率**微调。

**关键文献结论（直接解释了我方 I073 的失败）**：文献中「全局损失 + 排序辅助项」的正确形式是**交替更新（compositional）**，见 Zhu et al., *Compositional Training for End-to-End Deep AUC Maximization*, ICLR 2022——形式是 `L_AUC(w − α∇L_CE(w))`，内层走 k 步 CE、外层走 1 步 AUC。**没有任何论文报告过 `L = L_BCE + λ·L_AP` 这种加权和的最优 λ**，LibAUC 教程也从不做加权和。这解释了为什么 I073 的 L3/L4 加权式排序损失全部有害。

**文献空白（对我方有利）**：检索确认**没有 PFP / CAFA 类工作把 pAUC 或 AUPRC 作为训练目标**——CAFA 系列用 AUPRC 评估，但参赛方法普遍训 BCE/CE 变体。我方诊断出的「头部排序缺口」在文献里没有现成解法。

**验收**：主指标 `TPR@FPR=0.069` 上升**且**融合 Macro F1 不下降。若前者升、后者降，说明提升发生在提交阈值未使用的区域，视为无效。

### 辅助（低成本，最先做）— 标签级误差结构诊断

把 I075 的分支级审计下推到**标签级**（半小时工作量，零风险，为 A/B 提供投放方向）：

1. 逐标签秩相关 `ρ_l`（两分支在该标签正例上的 Spearman）
2. 逐标签**头部假阳性集合的 Jaccard 重叠**（头部 = 负例中排在前 6.9%），专门找重叠 < 0.4 的标签
3. 逐标签融合增益 `ΔF1_l = F1(A⊕B) − max(F1_A, F1_B)`

那 20–50 个「低重叠 + 高增益」标签就是融合收益所在，也是新信号该攻的方向。

## 六、风险与止损

- **每一路都必须以融合 Macro F1 为最终判据**，并按第三节三件套报告。中途不允许用独立指标做决策。
- **三路全负的预案**：若 A/B/C 全部关闭，则结论是「在禁用外部注释库的约束下，0.4475 已接近该信息闭包的上限」。这个结论本身有文献支撑——CAFA5 top-2 方案 ProtBoost（Chervov et al., arXiv:2412.04529）的最大增益来自**UniProtKB 中非实验性注释 + GO 层级 GCN stacking**，两者都被本赛事禁用。届时把资源转向**分析报告**（占评分 30%，目前尚未撰写）。
- **禁止事项**（避免重复劳动）：熵最小化自训练、纯伪标签迭代、无标注语料继续预训练、阈值校准/基数预测、对 A/B 两支同时施加排序损失、再训同任务同信息分支。
