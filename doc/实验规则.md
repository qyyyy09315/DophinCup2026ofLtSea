# 实验规则

## 验证协议

- **切分方式**：80/20 随机划分，`random_state=42`
- **切分一致性**：所有实验使用相同的 `train_test_split` 参数，保证可比性
- **不泄露**：测试集 (`test.csv`) 仅用于最终预测，绝不参与训练或验证

## 评估指标

| 指标 | 计算方式 | 说明 |
|---|---|---|
| **Macro F1** | 逐标签 F1 的算术平均 | 主要指标（比赛评分标准），跳过验证集无正样本的标签 |
| Macro Precision | `precision_score` per label → mean | 辅助参考 |
| Macro Recall | `recall_score` per label → mean | 辅助参考 |
| **Macro AUC** | `roc_auc_score` per label → mean | 阈值无关的排序指标 |
| Subset Accuracy | 完全正确预测的比例 | 极低属正常（500 标签） |
| Hamming Loss | 标签级错误率 | 越低越好 |

## 实验命名规则

### 实验层级
```
基线 (basl-*) → 改进 (描述性命名)
```

- **基线**：直接使用官方推荐方法或极简实现，目的是建立参照
- **改进**：在基线基础上变化特征、模型结构、训练策略等

### 实验记录要点


- 编号规则：基线模型 B001、B002...；衍生方法在对应基线编号后加小写字母，如 B001a；Transformer 与 CNN 的集成/组合实验用 TC001、TC002...（TC = Transformer + CNN，如 tc003-ensemble.py）；CNN 相关模型的实验用 C001、C002...（C 代表 CNN，如 cnn-c001.py）；Transformer 相关模型的实验用 T001、T002...（T 代表 Transformer，如 t001-*.py）；CNN 与 k-mer 序列相似性特征的集成实验用 CK001、CK002...（CK = CNN + Kmer，如 ck001-ensemble.py）；Transformer + CNN + k-mer 相似性特征的三路集成用 TCK001、TCK002...（TCK = Transformer + CNN + Kmer，如 tck001-ensemble.py）；RNN 相关模型及其表示应用用 R001、R002...（R = RNN/循环网络，如 r001-bilstm.py，R001a 为 R001 衍生）；预训练嵌入研究用 E001、E002...（E = Embedding，如 e001-pretrained-neighbor.py）；**嵌入 + 相似度特征融合（Embedding + kmer/DIAMOND 等 CK 系相似度）用 ECK001、ECK002...（ECK = Embedding + CK，如 eck001-fusion.py；融合链上的后处理也归 ECK，如 eck002-labelcorr.py）**；嵌入实验与融合后处理统一归 ECK，不再用 E 系列后缀（2026-08-19 用户确认）；**集成方法研究**（第二层分类器、级联、门控等，不改变基模型组合）用 I001、I002...（I = Integration，如 i001-classifier-comparison.py）。**系列前缀必须与实验内容语义一致**：模型类实验用 B/C/T/R/E，概率组合实验用 TC/CK/TCK/ECK，纯集成方法论实验用 I，禁止混用（如把集成方法实验编入 R 系列，把融合实验编入 E 后缀）。**小写后缀只给同一主干**（2026-08-22 / 08-23 / 08-25）：CK005 主干是 DIAMOND+多 k 融合，字母只到 a–f；后处理/门控改 I，组成表示改 ECK。08-25 新 k-mer 表示变体（缩减字母表/间隔种子/TF-IDF/IC/hub/共享近邻）另开 **CK006 / a–e**，禁止再占 CK005g–l（那些字母 08-22 已改挂为 CK005c / CK005d / I009 等）。腾讯表格历史行**编号列不改**，只改代码文件名列。
- 模型结构描述不加括号缩写，不使用 `v2` 等无意义标签，实验名直接用英文
- 参数不再单列，关键参数并入备注；只写关键改动（结构变化、损失函数、特征等），不写训练耗时
- 训练加速方案、训练轮次、LR 调度、逐标签阈值搜索等训练/后处理细节只写 `doc/日志/实验日志.md`，不写入腾讯实验记录
- **有效门槛（2026-08-25）**：融合实验相对当前锁 I019 半折 OOF ≥ +0.001；独立 CNN 对照 C002b F1(0.5)=0.2714，不要拿 F1(100) 去比 0.2714
- 集成/组合实验权重默认按验证集 Macro F1 选择（比赛评分标准为 Macro F1）；TC001/TC002 为早期 AUC 选权版本，Macro F1 选权版本编号为 TC001a/TC002a

## 文献引用记录规则

**目的**：所有实验的方法依据可溯源，便于后续查阅与报告撰写（分析报告占 30% 权重）。

### 三处同步记录

| 位置 | 格式 | 说明 |
|---|---|---|
| 脚本 docstring | `方法名 — 作者, 期刊/会议, 年份, doi:xxx / arXiv:xxxx.xxxxx` | 写清方法依据与文献；无文献依据的纯对照实验可省略 |
| 腾讯表格「参考文献/资料」列 | `方法名: 第一作者 年份, doi:xxx / arXiv:xxxx.xxxxx` | 多篇用 `; ` 分隔；只填该实验实际引用的 |
| `doc/日志/参考文献.md` | 完整引用格式 + 链接 + 应用实验清单 | 见下节规范；新增文献追加编号条目，不删改已有 |

### 完整引用格式（`doc/日志/参考文献.md`）

```
[序号] 方法名 — 一句话说明用途
- 引用格式：作者 姓+名首字母. 标题. 期刊/会议, 卷(期):页码, 年份.
- 链接：https://doi.org/xxx（正式出版）或 https://arxiv.org/abs/xxxx.xxxxx（预印本）
- 应用实验：编号（方法或特征来源）
```

- 作者列出全部或前 6 位 + et al.（≥7 位时）
- 预印本（bioRxiv/arXiv）标注预印本与年份；正式出版用 DOI 链接
- 新增文献时：脚本 docstring → 腾讯表格列 → `doc/日志/参考文献.md` 按顺序补，编号顺延

### 现有文献清单

完整引用格式见 `doc/日志/参考文献.md`，腾讯表格已按实验行回填。日志怎么读、怎么写见 `doc/日志/README.md`（禁止默认通读全部日志）。

每次实验完成后：
1. 读取 `rel/{缩写}_val_metrics.json` 或 `rel/{编号}_report.json` 获取指标
2. 写入腾讯文档对应行（分析性实验除外）
3. 追加 `doc/日志/实验日志.md`，勾 `doc/日志/待办.md`，更新 `doc/代码索引.md`

## 实验流程

1. 编写独立 `.py` 脚本，确保可复现；**所有循环型耗时段（逐标签训练/推理/阈值搜索/网格扫描等）默认加进度条（tqdm）**，便于手动运行时长监控
2. 手动运行脚本（`python {script}.py`）
3. 读取 `rel/` 下的指标 JSON
4. 填写腾讯文档表格
5. 按 `doc/日志/README.md` 写入对应日志（实验 → 实验日志；调研 → 文献调研）
6. 对比分析，决定下一步方向
